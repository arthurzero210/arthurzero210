# 👋 About Me

I'm a self-taught software developer from Brazil who enjoys turning ideas into real projects.

Most of my work revolves around automation, developer tools, operating systems, embedded software and game development. I enjoy understanding how things work internally—from high-level applications down to low-level programming.

Currently, I'm expanding my knowledge in software engineering, firmware development and computer architecture while contributing to personal open-source projects.

- 🔭 Working on embedded systems and developer tools
- 🌱 Learning Assembly, C#, Python and software architecture
- 💻 Passionate about low-level programming and operating systems
- ⚡ I enjoy building things from scratch just to understand how they work
